# ゲーム補足知識 harness

**言語:** [繁體中文](../zh-TW/game-knowledge.md) · [English](../en/game-knowledge.md) · [日本語](game-knowledge.md)

補足知識ページは、追加、編集、テキストフォルダのインポート、有効化、無効化ができます。開発モードではプロジェクトの `knowledge/` に、実行時はゲームデータディレクトリの `knowledge/` に保存されます。このデータは復元コンテンツのデフォルト値とは独立しており、イベントリセットで消えることはありません。

https://agentskills.io/specification の YAML frontmatter とフォルダ規約を採用しています。

```text
my-knowledge/
  KNOWLEDGE.md
  references/background.md
  references/details.md
```

KNOWLEDGE.md には name、description が必須で、name はフォルダと一致させます。メインファイルには検索用の説明と本文の索引のみを置きます。完全な知識はテーマ別に references/*.md に保存します。背景、定義、詳細、例、未検証事項を含みます。references には内容を置き、出典一覧や外部 URL は置きません。このバージョンはテキスト参照型の runtime であり、プログラムを実行せず、バイナリ画像／PDF も読み取りません。

チャット、LINE、イベント、選択肢の演出、Twitter のタイムラインは、オンデマンド検索を共有します。Twitter の返信や配信画像の決定にも使用できます。まず各項目につき名称 40 件、説明 180 文字までを送り、モデルが単一ターンの `read_knowledge` で項目を選択します。複数項目を同時に選択できます。システムは各項目のメインファイルと本文を自動読み込みし、メタデータと JSON/YAML 形式を解析し、読めるテキストとして応答モデルに注入します。読み込み時、タイトル、ファイル名、フィールド名に基づいて本文を削除しません。応答モデルが意味に基づいて事実を採用し、出典一覧、索引、無関係なノイズを無視します。各ファイルは最大 4000 文字、総参照本文予算は 12000 文字です。検索出力は 300 tokens に制限されます。これは文字予算であり、正確な tokenizer カウントと同一ではありません。

AI が知識を作成する場合、索引と少なくとも 1 つの本文ファイルを生成する必要があり、最大 10 ファイルです。LLM は提出前に意味に基づいて段落ごとにレビューし、出典説明、外部 URL、ノイズを自ら取り除き、知識の詳細と不確実性を保持します。プログラムは構造のみを検証し、実際の本文ファイルに基づいて索引を作成します。タイトル、キーワード、ファイル名で本文を削除・変更せず、検索結果を別途保存もしません。Web Search は整理された手掛かりを提供するだけで、要約を全文検証として扱ってはいけません。不確かな情報は本文に直接明記します。本文が欠落している、本文が長すぎる、モデル出力が途中で切れている場合は保存しません。

知識の内容はその回の生成にのみ追加され、長期のチャットメモリには書き込まれません。知識がない場合、追加のモデルリクエストは発生しません。検索の失敗は元の生成にフォールバックします。すべてのパスは knowledge ルートディレクトリに限定され、パストラバーサルとシンボリックリンクを拒否します。API は Editor の認証と同一オリジン制限を引き継ぎます。ツールはプログラム実行、ネットワーク、データベース、秘密の読み取り権限を付与しません。ドキュメントは信頼できない参照であり、キャラクター、ゲームルール、出力構造を上書きできません。

容量制限: 知識 40 件、1 回 100 ファイル、1 ファイル 64KB、総テキスト 1MB。UI からテキストファイルをアップロードします。ディスク上で直接変更した後は再スキャンできます。変更と無効化は次回の生成で有効になります。

主要プログラム: `server/knowledge.ts`、`server/knowledge-tree.ts`、`server/knowledge-generate.ts`。回帰テスト: `tests/knowledge.test.ts`、`tests/knowledge-tree.test.ts`、`tests/knowledge-generate.test.ts`。上記の検索は任意の追加モデルリクエストです。失敗した場合は、知識を引用したと称するのではなく、元の会話または投稿フローを続行します。
