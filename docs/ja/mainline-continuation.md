# 第4～9巻 主線イベント補完

**言語:** [繁體中文](../zh-TW/mainline-continuation.md) · [English](../en/mainline-continuation.md) · [日本語](mainline-continuation.md)

第9巻の帰り道イベントは、第8巻の告白を完了していることが別途必要で、重要な記憶を飛ばさないようにしています。イベントは既存の学年・月の規則に従って出現し、前提イベントを完了した後に該当する場所へ向かいます。

実装の入口は `core/mainline-continuation.ts` の `mainline-continuation-v1` です。`core/story.ts::upgradeStories` は、小説の導入と桃園中學の後に接続します。このパックは、ユーザー整理の中の推測のすべてをゲームの既成事実に変換するものではありません。保守時には、`beats` の学年、月、場所、前提条件を項目ごとに照合する必要があります。回帰テストは `tests/mainline-continuation.test.ts` にあります。

整理では、チョコレートの最終的な受け取り手、百メートルの正確な勝敗と時間、温水が迷う時の姿、飛驒の三角関係の最終的なカップリングは明示されていません。このバージョンは自作にそれらを原作の結論として補完することはありません。勝負や関係の後続は、勝敗／カップリングを確定しない同人としての場面でつなぎます。

各イベントには三種類のプレイヤー応答があり、好感度の変動は +3、+1、-3 です。追加イベントには全て利用可能なイラストがあり、現在はオリジナルの状況背景を流用しています。水族館と結婚式は専用の場面イラストではなく、公式原作の挿絵の代わりにもなりません。桃園中學は独立したオリジナルの学校背景を使用します。

既存コンテンツの読み込み時には `mainline-continuation-v1` で一回きり追加され、カスタムコンテンツとその後の削除を保持します。既定値の復元やセーブデータの消去は不要です。月を過ぎたセーブデータの日付が巻き戻ることはありません。
