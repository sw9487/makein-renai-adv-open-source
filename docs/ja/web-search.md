# Web Search と AI ナレッジ作成

**言語:** [繁體中文](../zh-TW/web-search.md) · [English](../en/web-search.md) · [日本語](web-search.md)

Editor → システム設定には、Web Search と AI ナレッジ（ノウハウ）を作成するための項目があります。検索は SerpApi と Brave Search を利用しています。以下に設定と動作を説明します。

## 設定

- 検索エンジン：`SerpApi` / `Brave Search`
- 入力：検索クエリ、検索する Web ページのタイトル（プロジェクトに関連するもの）、または AI が生成したクエリ
- 設定場所：Editor → システム設定 → 検索 → API キーを設定

## 使い方

チャットウィンドウまたは Editor のバックグラウンドから検索を実行します。検索対象は「プロジェクトに関連する Web ページ」です。検索結果を選択すると、そのページのテキストを AI ナレッジとして保存できます。

## 注意点

- 検索は「プロジェクトに関連するかどうか」を人間が判断するための補助であり、自動でナレッジを決定するものではありません。
- AI ナレッジは保存されると、キャラクターシート、プロット、設定資料を生成する際に参照されます。信頼できない情報を混ぜると、出力の質が下がる可能性があります。
- 保存する内容は、出典を明記し、必要最小限に留めてください。
