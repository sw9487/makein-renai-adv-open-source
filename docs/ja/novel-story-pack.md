# 小説第4～9巻イベントパック

**言語:** [繁體中文](../zh-TW/novel-story-pack.md) · [English](../en/novel-story-pack.md) · [日本語](novel-story-pack.md)

このパックは、依然として6個の小説題材の「導入」イベントと18個の選択肢です。その後、別途 [主線續寫](mainline-continuation.md) が19個の継続イベントを追加し、桃園中學の探訪は別途 [桃園中學](momozono-map.md) を参照してください。小学館／ガガガ文庫の各巻の内容紹介に基づいて中核的なシチュエーションを確認します。また、書誌情報と試読ページも照合します。試読ページでは読める本文が提供されていないため、全章を照合したとは主張しません。ゲームの台詞、選択肢、応答はいずれも同人二次創作としての書き換えであり、原作の分岐や巻全体の結末を表すものではありません。

月と入口はゲーム上の便宜的な設定であり、小説の刊行月から推定したものではありません。選挙は既存設定の高2 7月の生徒会引き継ぎより前に配置されます。莉子と小春は既存の登場制限に従います。物語は、公開された紹介で確認できる提案、葛藤、準備の場面に集中しています。例えば、百メートル走で勝敗を無理に作り出したり、結婚式の提案で結末を捏造したり、旅行イベントで同人としての応答を小説の結末として扱ったりはしません。

## イラスト

既に存在し場面に合う6枚のローカル状況画像を使用します。`108` 生徒会室、`109` 温水家、`103` 走路、`102` 文芸部、`204` 生徒会の公務、`106` 駅。完全なファイル名は `content/assets/backgrounds/`（102、103、106、108、109）または `content/assets/cg/`（204）にあります。これらはプロジェクト既存のオリジナル素材であり、第4～9巻の挿絵ではなく、アニメの初期のスクリーンショットを小説後期のイベントCGとして代用したものでもありません。各イベントと素材の記録にはこの旨が示されています。

## 更新と検証

- `core/novel-events.ts` がイベントと `novel-volume-4-9-v1` 一回きりの更新を提供します。`core/story.ts::upgradeStories` は、このパック、桃園中學、主線續寫、公眾地點パックの順に接続します。本ファイルの6個の導入イベントを4～9巻の全イベントと誤って数えないでください。
- `content/game.json` にも同期して追加され、旧 editor が読み込む際に補われ、保存後はイベントパックのマーカーを保持し、後からの削除・変更を上書きしません。
- 後期の小説題材を読むために全ての前期イベントを完了する必要はなく、旧セーブデータが7月のイベントを逃すことで一連のチェーン全体が発生しなくなるのを防ぎます。一部の新キャラクターは、まず初対面を完了する必要があります。
- 新イベントはそれぞれ一つの学年／月に限定され、一度だけ完了できます。既存のマップのヒント、好感度の増減、記憶、アルバム解放が用意されています。
- `tests/novel-events.test.ts` は、6イベントの実際の探訪、前提と学年制限、プラス・マイナスの好感度、アルバム、一回きりの更新をカバーします。
